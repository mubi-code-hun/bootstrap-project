# Bootstrap Assignment

This repository contains two responsive Bootstrap 5 projects:

1. `restaurant/` — Olive & Ember restaurant landing page.
2. `travel-agency/` — WanderWise travel agency landing page.

## How to run
Open either folder in Visual Studio Code and open its `index.html` file with a browser (or use the VS Code Live Server extension).

Both projects use Bootstrap 5.3.3 from the official CDN, Bootstrap Icons, custom CSS, responsive grid classes, and remote Unsplash images. An internet connection is needed to load the CDN assets and images.

## Notes
The contact forms are front-end examples. They display the requested form fields but do not send messages to a server.
